How to use

What this site is, and is not

In class

One device between two students

Every activity is built for pairs sharing a screen, because the argument between the two of them is where the learning happens. Nothing needs an account, nothing is submitted, and nothing is stored. Close the tab and it is gone.

On any screen

Phones, laptops, the bench machines

Everything is tap-driven rather than drag-driven, so a phone works as well as a laptop. No installation and no login, which means no student spends the first five minutes of an activity failing to get in.

Not here

No lessons, no grades

Principle comes from assigned reading in published sources. Grades live on Canvas. This site holds only the interactive part of a meeting, and scores shown by an activity are feedback for the pair playing it and go nowhere else.

Design rule

The answer is in the room

Wherever an activity can, it turns on something a student has to read off the equipment in front of them: this bench, this pendant, this nameplate. Those are the questions that cannot be answered from anywhere else.
